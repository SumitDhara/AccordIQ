## Contribution Workflow

AccordIQ follows a focused branch-based development workflow.

1. Create a dedicated branch from `develop`.
2. Keep each branch focused on one logical change.
3. Commit changes using clear, conventional commit messages.
4. Open a pull request against `develop`.
5. Review the changes and address any required feedback.
6. Merge the pull request once the change is ready.

## Pull Request Workflow

AccordIQ uses focused branches and pull requests to keep changes isolated and reviewable.

Before opening a pull request:

- Keep the change focused on one purpose.
- Use a clear commit message.
- Ensure relevant checks pass.
- Provide enough context for the change to be reviewed.
